Краткое содержание
-
- Учебный проект для освоения экономики, баланса и работы с данными в играх на примере idle/clicker‑проекта в духе «Cookie Factory».

Цель и задачи тренажёра
-
Цель: Дать практический опыт построения игровой экономики: от ресурсов и событий до внешних конфигов и системы сохранений.

Основные задачи студента:
- Скачать/клонировать проект с GitHub (gd-trainer-04-economy).
- Открыть проект через Unity Hub и запустить готовый idle/clicker‑прототип.
- Разобраться, как устроена архитектура экономики: ресурсы, события, конфиги, сохранения.
- Создать новый ресурс на ScriptableObject и связать его с UI.
- Описывать экономику через игровые события и транзакции.
- Вынести параметры баланса во внешние файлы (JSON/CSV) и уметь их править.
- Реализовать сохранение и загрузку экономического состояния.

Приобретаемые навыки:
-
Понимание структуры экономической системы, работа с ScriptableObjects как носителями данных, настройка ресурсов и UI, проектирование транзакций и логов, загрузка баланса из внешних конфигов, реализация сохранений и миграций.

Итоговый результат:
-
После тренажёра студент понимает, как устроена экономика простого idle/clicker‑проекта, умеет добавлять ресурсы, настраивать события и транзакции, выносить баланс наружу и сохранять экономическое состояние. Эти навыки напрямую переносятся в финальный проект блока — прототип симулятора фермы.

Требование к ПО
-
- Unity Hub
- Unity Editor 6000.3.2f1 LTS
- Git

Инструкция по интеграции проекта из GitHub в UnityHub
-
Склонируйте репозиторий gd-trainer-04-economy через GitHub Desktop:
- Откройте ссылку на репозиторий из материалов курса.
- Нажмите кнопку “Code” → выберите Open with GitHub Desktop
- Если GitHub Desktop ещё не установлен, установите его по подсказке GitHub и повторите шаг.
- В окне GitHub Desktop выберите папку на диске, куда хотите сохранить проект (можете создать отдельную папку для учебных проектов).
- Нажмите Clone и дождитесь, пока полоска прогресса дойдёт до конца.

Добавьте проект в Unity Hub:
- Откройте Unity Hub и перейдите на вкладку “Projects”
- Нажмите кнопку “Add” (или значок “+”) → Add project from disk.
- В проводнике выберите папку, в которую вы только что клонировали gd-trainer-04-economy (корневая папка проекта).
- Нажмите Select Folder.

Откройте проект в нужной версии Unity и дождитесь первого импорта:
- В списке проектов Unity Hub найдите gd-trainer-04-economy.
- Убедитесь, что для проекта выбрана версия Unity, указанная в курсе (Unity 6.3 LTS). Если нет — выберите её в выпадающем списке.
- Нажмите по проекту, чтобы открыть его в Unity.
- При первом запуске дождитесь окончания импорта (обычно 2–5 минут).
- Откройте вкладку “Console” и проверьте, что нет красных ошибок (“Error”) и критических предупреждений.

Откройте основную сцену idle/clicker‑проекта:
- В окне “Project” разверните папку Assets/_Project/Scenes
- Найдите файл сцены CookieFactory.unity и дважды кликните по нему
- Убедитесь, что в окне “Hierarchy” отображаются основные объекты сцены

Запустите игру:
- Нажмите кнопку “Play” в верхней части Unity
