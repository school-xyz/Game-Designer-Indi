Тренажёр 4.3 «Физика и game feel прыжка»
-
4.3A
-
- [ ] Исправлены основные проблемы: прилипание к стенам, пролёты сквозь платформы.
- [ ] Односторонние платформы работают корректно.
- [ ] Студент понимает, какие физические параметры за что отвечают.

4.3B
-
- [ ] Все препятствия на тестовом участке проходимы.
- [ ] Управление ощущается честным, без неожиданных «подстав».
- [ ] Студент может объяснить, почему выбрал такие значения.

4.3
-
- [ ] Исправлены базовые физические проблемы.
- [ ] Настроен прыжок и движение под комфортный game feel.
- [ ] Студент понимает связь между физикой, настройками скрипта и ощущениями от игры.

Тренажёр 4.4 «Tilemap и создание участка уровня с опасностями»
-
- [ ] Создана рабочая платформа с корректными коллизиями.
- [ ] Слои Tilemap отображаются в нужном порядке.
- [ ] Rule Tiles автоматически формируют аккуратные края.
- [ ] Опасности на отдельном слое работают корректно.

Тренажёр 4.5 «Свой небольшой уровень (блокаут)»
-
- [ ] Уровень проходим от старта до финиша, без невозможных участков.
- [ ] Есть логичная структура с обучением, нарастанием сложности и финальным челенджем.
- [ ] Есть чекпоинты перед сложными участками.
- [ ] Итерации и изменения задокументированы в LevelDesignTemplate.md.
